# Job Posting Classification and Analysis

This project is a Machine Learning and Natural Language Processing based system that automatically classifies job descriptions into categories such as **Data Science, Software, and Marketing**.

It also provides **job market analysis** through skill detection, visualizations, and an interactive Streamlit dashboard.

## Features

- Job category prediction
- Skill detection from job descriptions
- Confidence score for predictions
- Job market analytics dashboard
- Word cloud visualization
- Dataset explorer

## Technologies Used

- Python
- pandas
- numpy
- nltk
- scikit-learn
- matplotlib
- seaborn
- plotly
- streamlit
- wordcloud
